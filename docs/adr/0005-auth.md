# 0005. Auth: Better Auth with magic link

Date: 2026-09-22
Status: accepted


## Context

Groups of friends need low-friction sign in. WhatsApp OTP is attractive
but needs Meta business verification, approved templates and per
message cost.


## Decision

Better Auth with the magic link plugin and Resend for email in v1.
WhatsApp OTP later through Better Auth's phone number plugin with a
custom sender, without replacing the auth module.


## Consequences

- Free to run in v1.
- Sessions stored in the same database.
